MailLayer is published on npm as `@maillayer/core`.

The command-line binary is named `maillayer`. That means the package name and the command name are different on purpose:

| What you want                  | Use this                                                     |
| ------------------------------ | ------------------------------------------------------------ |
| Install the package            | `npm install @maillayer/core` or your package manager's install command |
| Run the installed CLI          | `npx maillayer ...`                                          |
| Run the CLI without installing | `npx --yes --package @maillayer/core maillayer ...`   |

Do not install the unscoped `maillayer` package from npm. It is a different package.

## Install in your app

Choose the package manager your app already uses.

<PackageInstallTabs />

Then import the client and adapters from the scoped package:

```ts
import { createEmailClient } from "@maillayer/core";
import { resend } from "@maillayer/core/resend";
```

The SDK and CLI run in server-side Node 20+ and Bun runtimes.

## Run the CLI once

Use the scoped package name when you want a quick adapter check without adding the package to a project.

```bash
npx --yes --package @maillayer/core maillayer adapters
```

Check a provider configuration:

```bash
RESEND_API_KEY="re_..." npx --yes --package @maillayer/core maillayer doctor --adapter resend
```

## Run the CLI from an installed project

After installing `@maillayer/core`, run the installed binary:

```bash
npx maillayer adapters
```

The command is still `maillayer`; the package you installed is still `@maillayer/core`. Avoid `npx maillayer` outside an installed project because the unscoped npm package is unrelated.

Bun users can use the same package and binary. If you want Bun to execute the one-off CLI command, use `bunx --bun --package @maillayer/core maillayer adapters`.

## Prerequisites

- Node 20 or newer is supported for SDK and CLI usage.
- Bun 1.1 or newer is also supported.
- Do not expose provider API keys in browser or client-side code.
- Provider credentials must be set in environment variables or passed with CLI flags.

## Verify the install

Check the published package and CLI version:

```bash
npx --yes --package @maillayer/core maillayer version
```

List supported adapters:

```bash
npx --yes --package @maillayer/core maillayer adapters
```
