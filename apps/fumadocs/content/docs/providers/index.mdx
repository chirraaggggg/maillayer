## Not sure which provider fits?

Each adapter is a thin HTTP client over the provider's own API. You can run
several adapters at once and route by message type, so the choice is not
permanent — see [fallbacks and retries](/docs/concepts/fallbacks-and-retries).

To add a provider that is not listed, read the
[adapter authoring guide](/docs/guides/authoring/create-adapter).
