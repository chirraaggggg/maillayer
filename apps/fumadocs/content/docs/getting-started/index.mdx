MailLayer is a library you install into your own Node.js or Bun application — not a hosted service. You keep your existing provider account and credentials; the SDK adds message validation, typed errors, retries, and fallbacks around one `send()` call.

## 2. Configure a client

Create one client with the adapter for the provider account you already have. Every adapter imports from its own subpath, so only the code that constructs the client changes when you switch providers.

```ts title="src/email.ts" lineNumbers
import { createEmailClient } from "@maillayer/core";
import { resend } from "@maillayer/core/resend";

export const email = createEmailClient({
  adapters: [resend({ apiKey: process.env.RESEND_API_KEY! })],
});
```

## 3. Send your first email

```ts title="src/send-welcome.ts" lineNumbers
import { email } from "./email.js";

const result = await email.send({
  from: "Acme <hello@acme.dev>",
  to: "ada@example.com",
  subject: "Welcome",
  text: "Hi Ada, your account is ready.",
});

console.log(result.adapter, result.id);
```

Every adapter returns the same normalized `SendResult`, so this code works unchanged with any supported provider.
